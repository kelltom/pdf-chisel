<objective>
Fix the review workflow image overflow bug in Convert mode by correcting two compounding CSS layout problems.

Purpose: The review image preview currently bleeds beyond the view bounds because (1) App.svelte's .content has padding: 24px that interferes with full-height children, and (2) ConvertMode's .mode-view uses overflow-y: auto in all states, which lets the browser grow the flex child to the image's natural height (e.g. 1188px for a 300 DPI A4 page) rather than clipping to the viewport-bounded height. Fixing both restores the intended "fit within view" behavior without breaking any other mode.

Output: Updated App.svelte (no padding on .content) and ConvertMode.svelte (conditional overflow class on .mode-view when in review/complete state).
</objective>
