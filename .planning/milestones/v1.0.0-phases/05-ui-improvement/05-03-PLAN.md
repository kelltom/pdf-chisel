**CRITICAL — Svelte scoping trap:** Svelte adds a unique attribute selector to scoped `<style>` rules (e.g., `[svelte-abc123]`). If a global rule in app.css AND a scoped rule in a component both target the same class, the scoped rule wins due to higher specificity. The migration requires DELETING the local copies, not just adding to app.css.
